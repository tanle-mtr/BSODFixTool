## 1. 工作流简报（摘要）

| 项 | 内容 |
| --- | --- |
| 目的 | 机器已蓝屏甚至进不了系统时，在**完全离线**、**零依赖**、可跑在 **WinPE** 的环境里查清蓝屏含义并安全修复引导 |
| 用户 | 现场维修工程师（主）、有经验的 Windows 用户、第一次用 PE 的操作者（受影响） |
| 实体 | 蓝屏代码 / 原因 / 步骤 / FAQ / 修复方案 / 修复步骤 / 系统卷 / 环境档案 / 命令日志 / 备份归档 |
| 界面 | 代码浏览器、代码详情、修复台、运行日志、关于 |
| 主链路 | code-browser → search-code → code-detail → open-repair-bench → repair-bench → run-one-click-repair → run-log → save-log |
| 约束 | 离线、零依赖、PE 可用、中文字体可能缺失、破坏性操作需二次确认 + 自动备份、硬件故障不可软件修复 |

**信息层级**：① 当前蓝屏是什么 ② 它为什么发生 ③ 现在能做什么（可执行动作）④ 执行到哪一步、结果如何。

## 4. 方向候选与选择

### 方向 A ·「控制台暗房」（选定）
诊断控制台布局：深色分层表面、等宽代码、单色高密度信息、状态色只用于风险与结果。鼠鼠以小尺寸出现在应用栏与空状态，修复台内换为安全帽动作素材。参与强度 standard。
- 证据链：机器宕机、用户处于紧张与暗环境、需要长时间读命令输出 → 深色高对比 + 等宽 + 单色为主。
- 排除：参考图的纸感与拼贴风。

### 方向 B ·「急救台」
左栏结果 + 右侧"急诊看板"，用大号色块与图标表达风险等级；鼠鼠以较大的动作姿态常驻右侧。
- 优势：风险一眼可见。
- 不选原因：色块化会让 73 条文本型内容变拥挤，且与"精读原因与步骤"的主任务冲突。

### 方向 C ·「向导式」
分步向导把查询→修复串成 4 步线性流程，每步一页，鼠鼠每步换姿态。
- 优势：低认知负担。
- 不选原因：现场维修需要来回对照原因与命令输出，线性向导会强制来回跳页，反而更慢。

**选择 A**：与"离线诊断控制台"的产品真相一致；已获用户预授权（保留鼠鼠特征、其余按当前产品重新设计），故直接实施并记录理由。

## 5. 组件规格（实现依据）

- 应用栏 64px：身份区（鼠鼠 + 标题 + 版本）+ 环境胶囊（PE/Windows、管理员、固件）+ 主操作「一键修复」。
- 左栏 400px：搜索框（等宽、可清空）、分类分段胶囊、可滚动结果行（44px：等宽代码 + 名称 + 严重度点）。
- 右内容：当前代码概览卡（代码/名称/严重度/分类/摘要/快速检查）→ 分段标签（原因 / 步骤 / 参数与 FAQ / 相关）→ 滚动正文。
- 修复台（全屏覆盖层）：左为环境与步骤清单（勾选 + 风险徽章 + 适用性说明），右为实时日志终端 + 鼠鼠动作素材与状态气泡；底部为「演练模式 / 命令预览 / 执行」。
- 状态胶囊与徽章：文字 + 颜色 + 形状三重编码，不依赖颜色单独传达。

### 同上下文比对结论

- **身份**：主界面与修复台中的鼠鼠保留灰圆照片头、小横耳、眯眼、人牙笑、白色豆身与胸前 V/U。

- **缺陷修复记录**：① 详情页滚动定位错误（渲染后跳到底部）→ 改为不自动滚动；② 长蓝屏名称溢出裁切 → 增加按可用宽度省略；③ 底部状态栏与修复台操作按钮被挤出可视区 → 改为 grid 三行布局；④ 低对比度小字 → 提升 `text_faint` 明度；⑤ PE 缺中文字体时无提示 → 状态栏给出明确告警。

### 可访问性

- 全部按钮为自绘控件，已开启 `takefocus`，可用 Tab 聚焦，回车/空格触发，并绘制聚焦环。
- 快捷键：`Ctrl+F` 聚焦搜索框，`Esc` 关闭修复台。
- 正文与次级文字对深色表面的对比度 ≥ 4.5:1（`text_faint` 已从 `#6b7a9e` 提到 `#8a99bd`）。
- 状态一律「文字 + 颜色 + 形状」三重编码，不依赖颜色单独传达；破坏性操作文案保持字面、精确。
- 遵循系统「减少动态效果」设置：开启后按钮过渡降级为瞬时切换。

### 离线 / 零依赖 / PE

- `tools/verify_offline.py` 静态扫描 6 个运行期模块：0 个网络模块导入；仅构建期工具 `scraper.py` 联网，且不打包。
- 数据 `bsod_data.json`（73 条）与 11 张 PNG 素材全部随 EXE 内嵌（`archive_viewer` 已验证）。
- 修复命令全部为 Windows 自带：chkdsk / sfc / dism / bcdboot / bootrec / bootsect / diskpart。
- PE 适配：自动识别 WinPE 与 UEFI/BIOS；缺失命令（如完整 Windows 中无 `bootrec`）自动跳过并写明原因；中文字体缺失时状态栏告警；窗口高度按屏幕自适应。
